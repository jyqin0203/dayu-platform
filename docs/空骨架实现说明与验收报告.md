## 1. 总体结论

当前代码已经实现了“代码即架构”的空骨架，整体与已确认设计一致：

- 单 Maven 工程；
- Java 17、Spring Boot 3.5.16；
- 按业务模块分包；
- 七个业务模块均有公开接口和核心 DTO；
- 七个模块均有 `skeleton` Profile 下的 Mock 实现；
- 普通用户、管理员和 Copilot 三条主流程已用 Mock 串联；
- ArchUnit 已建立第一版模块依赖约束；
- 没有接入 MySQL、Redis、真实文件系统、Nginx 或 AI 服务；
- 当前完整测试为 10 个，全部通过。

阶段结论：

> **通过（空骨架范围）。** 主架构和模块衔接与已确认规划一致；ArchUnit 两处规则盲区和 Catalog 生命周期 Mock 已修复，并通过完整测试。

当前代码能够证明模块接口可以编译、注入和串联，不能证明生产基础设施和真实业务实现已经正确。

## 3. 工程和运行方式

### 3.1 构建

实际文件：

- `backend/pom.xml`
- `backend/mvnw`
- `backend/mvnw.cmd`
- `backend/.mvn/wrapper/maven-wrapper.properties`

当前依赖与规划一致：

```text
Spring Web
Spring Validation
Spring Security
Spring Boot Test
Spring Security Test
ArchUnit JUnit 5
```

没有引入 MyBatis、MySQL、Redis、Spring Session、MinIO、MQ 或 AI SDK。

### 3.2 Profile

所有 Mock 和放行安全配置只在显式启用 `skeleton` Profile 时生效：

```java
@Profile("skeleton")
```

`application.yml` 已经不再把 `skeleton` 设置为默认 Profile。测试通过 `@ActiveProfiles("skeleton")` 显式启用。

这意味着：

- 测试可以使用 Mock；
- 普通启动不会自动加载 Mock 用户和 `permitAll` 配置；
- 生产环境仍需实现真实 Security 配置，否则当前骨架不能作为生产服务运行。

### 3.3 HTTP 接口现状

目前没有 `@RestController`、`@RequestMapping` 等真实 HTTP Controller。

以下目录只有架构占位：

```text
interfaces/rest/v1
interfaces/rest/legacy
```

因此当前测试验证的是 Java 模块 API，不是浏览器 HTTP API。

## 4. 模块实现总览

| 模块 | 实际实现 | 实际依赖 | 当前证明 |
| --- | --- | --- | --- |
| Catalog | 产品查询、草稿创建、修改、发布、停用 Mock | Shared | 产品目录和管理接口可以调用 |
| AssetIndex | 固定 WebP/NC 索引、扫描结果和查询 Mock | Catalog API、Shared | 四组资产接口可被其他模块调用 |
| Discovery | 预览、批次、NC检索、匹配和可用性 Mock | Catalog API、AssetIndex API | 查询编排方向正确 |
| Identity | 注册、登录、当前用户、退出、用户管理 Mock | Shared | 用户与管理员身份流程可串联 |
| Download | 下载授权、审计查询、统计和交付结果接口 Mock | AssetIndex API、Shared | assetId 下载授权链可串联 |
| Operations | 仪表盘、健康、扫描、审计和用户管理编排 Mock | 前五个模块 API | 管理员编排方向正确 |
| Copilot | 规则式自然语言查询 Mock | Catalog API、Discovery API | AI边界没有越过查询模块 |

模块依赖的实际代码方向与规划一致：

```text
Catalog      → Shared
Identity     → Shared
AssetIndex   → Catalog API + Shared
Discovery    → Catalog API + AssetIndex API + Shared
Download     → AssetIndex API + Shared
Copilot      → Catalog API + Discovery API + Shared
Operations   → Catalog/AssetIndex/Discovery/Identity/Download API + Shared
```

当前扫描未发现业务模块导入其他模块的 `application/domain/infrastructure` 包。
