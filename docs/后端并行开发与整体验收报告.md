## 2. 每个模块实际做了什么

| 模块 | 典型输入 → 操作 → 输出 | 代码入口与依赖 |
| --- | --- | --- |
| Catalog 产品目录 | 管理员提交 PRECIP、启用 REALTIME → 事务写产品/策略/审计并发布 → 公共产品详情 | `CatalogService`；自有 Repository，不依赖其他业务模块 |
| AssetIndex 数据索引 | 配置的 NC/WebP 根目录、手动/定时触发 → 解析文件名和元数据、幂等更新索引 → 真实 scanRunId、状态、计数、安全错误及变更事件 | `PersistentAssetScanner`、`IndexedAssetQueries`；依赖 Catalog API |
| Discovery 数据检索 | 产品、模式、UTC 时段、批次/时效 → 校验公开状态、查询索引、匹配下载候选 → WebP URL 或 NC 分页摘要 | `IndexedDiscovery`；依赖 Catalog、AssetIndex API |
| Identity 用户身份 | 注册/登录信息、当前 Session → 密码哈希/核验、独立认证会话、CSRF、角色/状态检查 → 当前用户与更新后的 Token | `IdentityApplicationService` 和安全适配；不依赖其他业务模块 |
| Download 文件下载 | assetId、用途、可信用户 → 检查 NC 与路径、记录授权、生成短期内容地址，再核验持有人/有效期 → LOCAL 字节流或 Nginx internal 转发 | `DownloadService`、`DownloadContentService`；只依赖 AssetIndex API |
| Operations 管理编排 | 管理员、时间/产品筛选 → 调用各模块公开能力 → 扫描历史、健康、用户及授权下载统计 | `OperationsApplicationService`；依赖 Catalog、AssetIndex、Discovery、Identity、Download API |
| Copilot 查询助手 | 自然语言、显示时区、当前页面 → 模型生成受控查询条件、Java 校验后调用真实查询 → 解释、筛选条件、白名单跳转动作 | `CopilotApplicationService`；依赖 Catalog、Discovery API，不执行下载或管理操作 |

每个方法的详细输入/行为/输出和测试范围已写在 [reviews](reviews/) 中的模块报告，无需通过背所有类名理解系统。

## 3. 实际联调路线

```text
管理员注册初始化与登录
  → HTTP 创建产品、配置模式、发布
  → 提交扫描，拿到真实 ID 并轮询完成
  → 同一个 RePPIC NC 关联 PRECIP + PLP，WebP 关联单产品

匿名访客
  → NC 条件检索 + WebP 预览（可判断对应 NC 是否存在）
  → 注册成功并建立 Session
  → 提交 assetId + purpose
  → 用内容地址取得与合成源文件逐字节相同的内容
  → 旧 search.php 对共享 NC 去重，再经 download.php 取得相同字节

安全与统计
  → 其他用户冒用内容地址：403
  → 普通用户访问管理端：403
  → 管理员看到真实授权次数/用户/文件统计
  → 管理员禁用该用户后，其旧 Session 再下载：401
```

完整链路测试为 `PlatformWorkflowIntegrationTest`：真实 Spring 应用、临时 MariaDB/Redis、合成数据文件、HTTP Session，不导入业务 Mock。先缓存空目录/空时间轴，再验证发布和扫描能使旧缓存失效；新旧下载各产生一条授权记录，统计授权次数为 2，但唯一用户和唯一文件仍各为 1。

## 4. 主 Agent 的验收，不只是接收子 Agent 的结论

- **会话与权限**：不接受进程全局“当前用户”；注册必须提交数据库后建立 Session；禁用/降权影响已有会话。
- **扫描语义**：不接受“同步执行后返回 202”或伪造任务 ID；失败根目录不能造成误删索引。
- **预报时间**：未来 validTime 不能被旧接口过滤；健康看最新 cycleTime，不能把未来有效时间误当作刚更新。
- **契约字段**：管理员下载统计使用约定的 `authorizedRequests` 等四字段，缺失时间保留 null，不编造计数。
- **下载边界**：检查申请人、TTL、文件变化、路径逃逸，真实流式/Nginx 字节验证与授权审计分开；不冒充“客户端完整下载统计”。
- **缓存与模型保护**：要求事务后失效、旧代际回填保护、Redis 故障回源；模型限制输入/响应、超时、分钟频率与同时在途数。
- **旧接口安全**：严格路径别名、UTC、结果去重与有界查询；服务器故障不能伪装成“没有数据”，错误不得泄露敏感细节。
