# 产品生命周期界面验收

日期：2026-10-03；分支 feat/frontend-session。未提交或推送；本轮所有产品写入验证均为隔离浏览器响应。

## 功能

管理概览 → 产品资料：创建产品草稿、发布、停用、重新发布。创建复用原资料表单，只增加创建时必填的编码/分类，编辑时不能修改两者。
状态路径：DRAFT → PUBLISHED → DISABLED → PUBLISHED；不提供物理删除。
所有创建和状态变更先确认，取消不请求写接口。发布前至少一个模式启用，色标/发布完整性仍由后端校验。

## 输入输出

| 函数/文件 | 输入 | 行为 / 输出 |
| --- | --- | --- |
| product-admin-client.js / create | 编码、分类及资料表单 | 校验字段，获取当前管理员 CSRF，单次 POST admin/products；返回草稿，不连带配置模式或发布 |
| lifecycleAction | 产品快照、publish/disable | 校验 ID/状态转换及发布前启用模式；非法动作不请求接口 |
| transition | 原产品快照、动作 | Session/CSRF、updatedAt 预检，POST admin/products/{id}/{action}；返回新状态 |
| admin-products.js | 用户点击、表单 | 创建/编辑共用表单，确认状态影响，提交期间防重复，成功刷新产品列表 |
| admin.html/admin.css | 原主题 | 创建按钮、创建专用编码/分类字段和状态按钮；延续局部适配，不改地图布局 |

不新增依赖或修改后端。模式配置、资料编辑与状态命令分开调用，不发送物理文件路径，不调用删除接口。
网络中断不自动重放 POST，提示先重新读取核对；编码重复提示更换编码。updatedAt 检查非原子锁，仍保留已有 GET/POST 并发窗口限制。
状态操作成功后更新产品列表；概览统计、健康状态需使用管理页顶部刷新读取最新值。
