# 用户管理验收（2026-10-03）

输入：邮箱/机构/角色/状态、页码；输出：每页20条用户公开信息。不读取或展示密码。
`user-admin-client.js` 封装 GET 列表与带当前 CSRF 的独立 status/role PUT；`admin-users.js` 负责确认、分页、状态反馈与失权清理。后端继续保护当前账号和最后一个有效管理员，不允许通过前端绕过。

验证：`npm test` 64 项通过、0失败/跳过，构建通过。新增4项覆盖白名单筛选、状态/角色请求、CSRF、自身禁用、最后管理员409及不重试写入。
Playwright：读取真实本地用户列表；隔离用户9999验证取消0次PUT、禁用/升级角色各1次PUT，按钮随结果更新。所有写请求均被测试拦截，未改变真实用户或权限；测试管理员随后退出。

前端采用管理页原有局部样式，没有新依赖。真实写权限变更仍需在专用可恢复测试账号验收；不应拿唯一管理员做负向破坏测试。
