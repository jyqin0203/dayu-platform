日期：2026-10-03；分支 feat/frontend-session。保留之前的管理员概览/扫描改动，本轮未提交、未推送、未修改真实产品。

## 范围

管理概览 → 产品资料 → 编辑。读取包括草稿/已发布/停用的管理目录，前端每页显示 20 条。
可编辑名称、单位、说明、生产方、算法名称、数据来源、官方网址、色标相对路径、色标要求和排序。
产品 ID/编码/分类/状态/模式只读。本轮没有新增、发布、停用、重新启用或模式配置按钮。
沿用 surgical-web-fusion 局部适配规则，不改观测台；产品弹窗复用暗色/青色主题，窄屏单列。

## 输入输出和文件

| 文件 / 方法 | 输入 | 操作和输出 |
| --- | --- | --- |
| product-admin-client.js / productForm | 后端管理产品 | 转为表单值；把公开色标 URL 还原成配置相对路径 |
| productPayload | 表单 | 校验名称、单位、排序、来源 URL、相对路径；只保留 UpdateRequest 白名单字段 |
| list | 可选产品编码 | GET admin/products，返回真实管理目录 |
| save | 原始产品快照、表单 | 校验输入、读取管理员 Session/CSRF、重新获取产品比对 updatedAt，单次 PUT admin/products/{id}，返回更新结果 |
| admin-products.js / mountProducts | 失权回调 | 列表展示、客户端分页、表单回填、保存与错误状态；reset/load 接入概览 |

admin.html/admin.css 增加产品表格及编辑弹窗；admin.js 通过统一失权回调清除产品、扫描与概览。
无新第三方依赖，无后端接口、数据库或模块依赖改动。

## 交互和安全

- 保存只包含资料字段，不发送状态、模式、产品编码或分类，不会通过 PUT 顺带变更生命周期。
- 输入失败或后端 422 时保留表单；成功刷新列表；未保存关闭需要确认，保存中禁止重复提交和关闭。
- 读取失败不会自动重发保存；超时提醒重新读取后核对结果。
- 预检 updatedAt 可发现提交前已经发生的变化，但不是原子并发控制：GET 与 PUT 间仍有竞争窗口，未声称替代后端版本锁。
- 失权关闭编辑框并清除数据；普通刷新/窗口重新可见时不静默丢弃编辑输入。
- 后端继续执行已发布产品的色标/发布约束。前端路径检查不能代替服务端校验。
