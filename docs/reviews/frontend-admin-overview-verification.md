## 用户路径与范围

管理员登录 → 账号弹窗“管理概览” → `/admin.html`。匿名或普通用户直接访问只显示身份/权限提示；静态 HTML 本身可以公开获取，受保护的是后端管理数据。
界面沿用观测台暗色/青色样式，独立页面避免把管理操作塞进地图。当前只展示数据，不新增产品写入、扫描触发、用户管理或审计明细。

无新第三方依赖、无后端代码修改。只请求现有公开契约，不访问数据库或存储目录。
数据缺失/延迟统计是按产品去重，不同模式可能让同一产品同时进入两类，不能把两项相加当作产品总数。
下载只显示“授权次数”，不表示文件已完整传输或保存。没有扫描记录时显示空状态，不伪造任务。
