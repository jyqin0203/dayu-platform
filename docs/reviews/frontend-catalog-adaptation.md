# 前端第 2 步之一：公开产品目录适配

日期：2026-10-03。基于已合并的 PR #11，分支 `feat/frontend-data-adaptation`。

## 闭环与变更

页面 → `/api/v1/products` → Catalog 的已发布产品及启用模式 → 播放器目录。
所选产品 → `/api/v1/products/{code}` → 公开色标 URL → 图片加载。
图片列表仍调用已确认的 Legacy Discovery 接口，本轮不改变时间窗口、不写数据库。

| 函数/文件 | 输入 | 行为与输出 |
| --- | --- | --- |
| `expandCatalog`，catalog-adapter.js | v1 产品列表 | 将每个启用模式展开为播放器条目；携带单位、产品编码和过期阈值；不补草稿或禁用模式 |
| `loadColorbar`，catalog-adapter.js | 产品编码，可注入 fetch | 读取公开产品详情，返回同源色标路径或 null；HTTP/地址错误抛出异常 |
| `geometryFor`，product-geometry.js | 播放器产品 ID | 去掉 FCST_ 模式前缀后复用已确认的实况定位参数 |
| `unpad`，product-geometry.js | 图片及产品 ID | 预报与实况使用同样裁边检查；尺寸不符仍拒绝，不猜测裁剪 |
| app.js | 上述目录和详情结果 | 展示后端名称/单位，异步切换时忽略旧产品色标结果；地图点的预报入口按已启用模式决定 |

未新增第三方依赖或改变后端模块依赖。原页面布局和样式未变。

## 限制和下一步

当前没有真实气象帧索引，因此浏览器检查只证明页面启动、空结果和交互可用，不证明真实贴图空间精度、动画与完整预报链路。
色标配置与静态文件是否存在是两回事；本轮不修改本地存储配置或发布草稿。
staleAfterMinutes 已传入页面模型，尚未用于过期提示。
下一小步处理时间轴：核对有效时间/起报时间、实时窗口及降水多时效加载，不在本轮顺带实现。
