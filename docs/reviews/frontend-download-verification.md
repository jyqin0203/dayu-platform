## 用户路径

数据检索 → 选中文件“下载” → 检查登录 → 未登录时打开登录/注册弹窗 → 回到原文件 → 填写 10～2000 字用途 → 申请下载 → 点击“下载文件”。

检索弹窗不关闭，条件、页码和结果原位保留。下载弹窗保存所选 assetId/文件名快照，登录失败或取消不清除。登录成功（含注册自动登录）关闭账号弹窗，返回原文件。授权时登录过期也保留用途，让用户重新登录后手动提交。
保留的是当前页面内存状态，不承诺刷新或关闭浏览器后恢复。

## 安全与大文件

- POST 仅含 assetId 和 purpose，不提交用户 ID、角色、机构或物理路径。
- 写入前读取当前 CSRF；权限和文件可用性仍由后端判定，前端状态不代替鉴权。
- 禁止自动重试可能已成功的授权 POST；超时提示“授权请求未确认”。关闭弹窗后迟到响应不会自动发起下载。
- 原生链接交给浏览器下载，不使用 fetch().blob() 加载整份 NC，不把大文件保存在 JS 内存。
- 链接使用 download 和 target=_blank/rel=noopener，错误内容不会替换检索页面；内容接口仍会再次鉴权。若内容阶段过期或失权，用户可能在新标签页看到服务器错误，需回到原页重新申请。
- 页面只提示“已获授权”或“已发起下载”，不会宣称用户已完整保存；实际状态查看浏览器下载记录。
- 密码、CSRF、授权信息、用途不写 localStorage/sessionStorage。
