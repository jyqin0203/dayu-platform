顶部独立“数据检索” → 产品、启用模式、有效时间范围 → 可选起报时间/预报时效 → NC 分页结果。入口与“登录/账号”并列，账号弹窗不再包含检索入口。

## 输入输出与文件

| 文件 / 函数 | 输入 | 行为及输出 |
| --- | --- | --- |
| scientific-client.js / toUtc | 分钟级表单时间、UTC 或 Asia/Shanghai | 严格验证日期，转换为 UTC ISO；不依赖电脑时区 |
| timeInput | UTC 时间、显示时区 | 返回对应 datetime-local 值；时区切换保留同一时刻 |
| scientificParams | 条件快照、页码 | 生成查询参数；固定每页 20 条、一基页码；实况不携带预报条件 |
| searchScientific | 条件、页码、可注入 fetch/AbortSignal | GET /api/v1/scientific-assets，返回 items/page/pageSize/total；错误不伪装为空数组 |
| scientific-search.js / openScientificSearch | 用户点击 | 打开弹窗并读取已发布产品/启用模式，按需发起查询并渲染 |
| scientific-search.css | 原主题变量 | 桌面两列表单、手机单列，弹窗内部滚动 |

两个 HTML 入口独立加载检索脚本与样式，账号模块不再导入检索模块；package.json 纳入新增测试。
响应显示文件名、MiB 大小、关联产品、状态、有效时间、起报时间、时效；动态文本使用 textContent，不拼接 NC 下载路径或 HTML。
前端只依赖 Catalog/Discovery 公开 HTTP 接口，无新第三方包、无后端依赖变更。

## 交互与边界

- 筛选与结果明确显示 UTC/北京时间 UTC+8；当前仅开放这两种无夏令时的时区，未宣称支持全球任意时区。
- 时区切换同步转换已填时间，保持实际时刻；重新检索后按所选时区展示结果。
- 条件变化清空旧结果并停用旧分页；新请求/关闭弹窗取消旧请求，用请求代次防止迟到响应覆盖新条件。
- 查询超时 15 秒；无产品、目录错误、无 NC、非法条件和服务失败分别提示。
- 历史 NC 查询不套用地图的 24h/三天限制。预报起报时间不填时原样省略，具体候选由后端查询决定。
