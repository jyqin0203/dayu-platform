# 下载授权审计筛选与分页验收

日期：2026-10-03；分支 feat/frontend-session。本轮未提交或推送，未新增/修改授权事件。

## 用户路径与范围

管理概览 → 下载授权记录 → UTC 授权时间范围、可选产品编码/用户 ID/机构 → 查询 → 每页 20 条。
默认最近 30 天，支持翻页。结果包含事件 ID、用户 ID、机构快照、文件、产品快照、资产 ID、预期大小、用途、授权时间与状态。
页面明确授权不等于完整传输，不计算下载完成率，不提供导出或批量下载。
采用局部适配方式扩展管理页，不改已有产品/扫描功能或观测台。

## 文件与输入输出

| 函数 | 输入 | 操作 / 输出 |
| --- | --- | --- |
| audit-client.js / auditParams | 表单快照、页码 | 验证 UTC 日期/范围、产品编码、正整数用户 ID、机构长度；生成一基分页参数 |
| loadAudits | 条件、页码、可注入 fetch/AbortSignal | 只读 GET /api/v1/admin/download-audits；返回 items/page/pageSize/total，保留 401/403 错误状态 |
| admin-audits.js / mountAudits | 失权回调 | 绑定表单和分页，提供 reset/load 给概览；条件变化清空旧结果，迟到响应不覆盖新条件 |

admin.html/admin.css 增加局部筛选和结果区域，admin.js 身份通过后读取，失权清理。
没有新增第三方依赖、后端接口或数据库改动。筛选与前端渲染不替代服务端管理员鉴权。

## 安全与行为

- 用途、机构、文件名仅 textContent 展示；不执行 HTML，不生成物理下载路径。
- 同源 Cookie、no-store；15 秒超时，错误与空结果区分。
- 条件变化取消旧请求，翻页使用已提交条件快照；总页数缩小时回退末页。
- 401/403 清空审计列表并隐藏整个管理数据。
- 本筛选只影响下方授权明细，不改变上方概览最近 30 天的聚合统计。
