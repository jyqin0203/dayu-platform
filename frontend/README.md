# Frontend

基于 2026-10-03 生产现代版迁移，保留观测台视觉与 Cesium，已接入新后端。source-manifest.json 记录的是迁移前来源哈希，不代表适配后文件仍逐字相同。

## 当前入口

- /：观测台，顶部独立数据检索、AI、账号入口。
- /admin.html：管理员概览、产品资料与模式/生命周期、扫描、用户和下载授权审计。
- 经典页/旧英文页不再提供独立入口，页面不链接旧 PHP 管理页。
- Catalog/身份/检索/下载/管理/AI 使用 v1；地图帧列表保留已确认 Legacy 兼容接口。
- Cesium 固定为 npm 1.146.0 的本地浏览器资源，不依赖天地图 CDN。

## 本地开发

需要 Node.js24（最低22）以及已启动的 Java17 后端：

~~~powershell
cd frontend
npm.cmd ci --ignore-scripts
npm.cmd run check
npm.cmd test
npm.cmd run dev
~~~

打开 http://127.0.0.1:15173/ 。默认代理后端 http://127.0.0.1:18080 ；自定义用 DAYU_FRONTEND_PORT/DAYU_BACKEND_URL，仅支持本机HTTP。
静态服务只开放 public 与 Cesium浏览器资源，保留Cookie/CSRF和二进制传输；不开放配置、数据库或NC物理目录。

## 构建与验证

~~~powershell
npm.cmd run build
~~~

输出 dist/，包含 Cesium、版权声明和前端页面；构建只替换本项目标记的目录，拒绝删除未知输出。node_modules/dist/真实数据不提交Git。
CI执行锁文件安装、全部浏览器脚本语法检查、所有 *.test.mjs、构建与Cesium文件检查。通过不等于真实数据/生产部署已经验收。

现有本机证据和分步输入输出见 docs/reviews/frontend-*.md；真实亮温/色标、Session和一次Qwen查询已联调。管理员写操作主要使用隔离响应，不应冒充生产写操作验收。
新电脑必须重新生成配置、初始化产品并扫描样本；本机400d历史窗口、色标配置和数据库不会跟随Git迁移。详见 [迁移与验收指南](../docs/前后端迁移与最终验收指南.md)。

生产静态路由参考 nginx-static.example.conf，需与现有API/受控下载配置合并；不要开放 /netcdf/。本仓库没有自动发布生产环境。

## 独立流畅度预览

在独立 worktree 中使用已有的本机静态/API 服务作为代理上游，不替换原站点：

```bash
DAYU_FRONTEND_HOST=0.0.0.0 DAYU_FRONTEND_PORT=15175 DAYU_BACKEND_URL=http://127.0.0.1:15173 npm run dev
```

从另一台电脑访问 `http://服务器IP:15175/`；默认开发命令仍只监听回环地址。
本分支切换产品时保留旧画面，新帧与产品信息准备好后一起切换。所有图片缓存只在当前页面内存中生效，关闭/刷新页面会释放，不缓存身份或下载授权。

### 当前缓存与交互策略

| 内容 | 预算/规则 | 刷新与淘汰 |
| --- | --- | --- |
| 压缩 WebP | 最多 96 个条目、48 MiB，LRU | 超过 3 分钟后复用前检查版本；版本变化同时淘汰对应解码结果 |
| 已解码/裁边图片 | 最多 10 帧、估算 RGBA 96 MiB | LRU 淘汰；压缩数据还在时重新解码但不重复下载 |
| 已显示气象图层 | 最近最多 3 层、估算源纹理 96 MiB，当前层必须保留 | 切换只显示一层，过旧图层销毁；Cesium 的实际 GPU 开销不等于此估算值 |
| 时间轴列表 | 切产品时短暂复用 30 秒 | 每 3 分钟后台检查；手动刷新立即重查 |
| 色标地址 | 3 分钟、合并进行中的同产品请求 | 请求失败可重试；手动刷新绕过缓存 |

时间轴拖动时，已解码帧立即请求显示；未准备帧停留 120ms 后加载，松手立即加载最终选择。快速拖动取消过时请求，时间标签只在对应画面就绪时提交。
预加载根据浏览方向准备相邻 3 帧，开始播放时恢复向前预加载。重复点击当前产品不重置当前时次，重复选择当前帧不重新创建图层。打开目录只更新选择状态，不再重新加载色标。
快速切产品会取消过时的列表请求；播放调度使用独立代次，避免暂停/重启或改速度时旧回调产生重复计时。

### 自动更新与业务边界

页面每 3 分钟检查当前产品列表及解码工作集的 HTTP 版本，隐藏标签页时暂停，返回后立即检查。压缩缓存中的其他帧在再次使用时按版本检查期限校验，避免每轮为所有缓存帧发送请求。
列表更新按文件路径保留当前时次和播放状态；时次已被移除时选择最近可用时次并提示。新预报批次仅提示，通过“最新”切换，不混合起报批次。
版本优先使用 ETag，当前服务未提供 ETag 时使用 Last-Modified + Content-Length；版本改变才重新获取并处理图片。
这不是内容哈希：若上游覆盖文件并同时保留修改时间和文件大小，现有响应头无法识别，仍需手动刷新。
手动刷新清除两层图片缓存并重新获取当前产品列表与色标；失败时保留现有可见图层。
生产索引配置当前为 fixed delay 20 分钟，代码默认 15 分钟；本分支不改变扫描调度。
实况仍显示 24 小时内每 30 分钟一帧；UTC 时间、预报批次/时效、产品发布规则、图片裁边、投影和地理坐标均不改变，不插值造帧、不从颜色反推数值。

### 首屏和二维渲染

底图按原始 Natural Earth 坐标、颜色和 Canvas 填充规则预生成，带内容哈希文件名；首次打开不再现场绘制整张底图和编码 PNG，矢量边界另行异步加载。
可选维护命令：`node generate-basemap.mjs /path/to/playwright/index.mjs`。生成器只用于开发维护，不是运行时依赖；资源源文件 SHA256 写入 `basemap-resource.js`。
预览服务对版本固定的 Cesium 和带哈希的底图缓存 30 天；业务 JS/CSS 用 ETag 重新校验，HTML 不缓存。API、身份和下载响应保持上游策略；生产 Nginx 只更新了配置示例，尚未部署。
二维边界使用普通折线，三维恢复贴地边界。二维移动时渲染倍率降至 min(1, 静止倍率 × 0.8)，停稳恢复；气象原图不降采样。
二维移动期间面板暂停 backdrop blur，停稳恢复；三维沿用原设置。

### 核心方法与验证

- `prepareFrame(file, productId)`：校验缓存版本，复用压缩字节/解码结果，返回可交给 Cesium 的图像；取消和网络失败由调用方处理。
- `refreshFrameVersions(productId, files, signal)`：检查当前解码工作集，清除过期/变化的缓存，返回变化文件集合。
- `createFrameLayers(viewer).present(texture, product, isCurrent, opacity)`：复用有限图层，等待渲染就绪后切换；过时请求返回空，失败保留当前层。
- `createColorbarCache()`：返回支持强制刷新的色标地址读取函数，短期复用请求和结果。

快速验证：`npm run check`、`npm test`、`npm run build`。
同步 main 后 Node 测试 90 项通过，包含压缩缓存复用、版本变化、取消竞态、图层池上限/复用和静态资源缓存策略。
浏览器检查覆盖拖动未松手即预览、快速拖动最终选择、当前产品/最新/目录无重复加载、连续解码超过 10 帧后的压缩缓存复用、图层数量上限及快速产品切换。
自动更新验证通过拦截响应模拟列表新增和版本变化，不改写真实数据或触发生产扫描。服务器浏览器使用软件渲染，不作为用户显卡上的 FPS 承诺。

同步 main 的 Copilot 时间上下文：实际显示帧更新时统一发送 `dayu:visible-time`（ISO UTC），不发送尚未显示的拖动目标。浏览器已核对首帧与拖动后的事件时间和画面标签一致，未调用模型服务。
